# Week1

This Rust binary project, `week1`, serves as the starting point for the first week of the Rust bootcamp.

## Purpose

It contains a simple `main.rs` generated by `cargo new` and is intended for practicing Rust syntax and building small utilities.

## Copilot

One aspect of GitHub Copilot I found interesting is its ability to suggest idiomatic Rust code even when you only type a comment about what you want to do. It can often provide complete function implementations or examples that follow best practices, saving time during development.
